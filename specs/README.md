## SDD 流程约定

1. **规格先行**：任何代码实现前，对应规格必须已存在于本目录并通过评审
2. **单一事实源**：实现与规格不一致时，先改规格（走变更记录），再改代码；禁止"代码先行、规格后补"
3. **需求冲突仲裁**：规格与《部分功能需求.docx》原始业务需求不一致时，**必须经需求方书面确认**后方可写入规格（见各文档"需求偏离登记"节）
4. **同步更新**：开发过程中规格的任何修订，在同一提交内完成文档与代码的同步
