# DESIGN.md — 《AI 播单编排工作台》产品演示

## 画布与母版（1280×720）
| 母版区 | 位置 | 规则 |
|---|---|---|
| A 标题块 | 0–120px | 主标题 34px bold #1E5FBF 主题色；章节编号小标 14px 灰 |
| B 内容区 | 120–660px | 一切正文/示意/卡片 |
| C 页脚条 | 660–720px | 左：项目名「AI 播单编排工作台」14px #8B8FA3；右：页码 NN / 14 |
| padding | 上下 20 / 左右 64 | 封面/扉页/结束页可自定义 |

## 色板（≤4 hex，品牌蓝系，与产品一致）
| 角色 | hex | 用途 |
|---|---|---|
| 主色 | #1E5FBF | 标题、主按钮、大色块、品牌底 |
| 辅色 | #EFF6FF | 卡片底、浅底分区 |
| 强调色 | #3B82F6（亮蓝）/ #F59E0B（琥珀，仅焦点数字） | 巨型数字、CTA、关键标注 |
| 中性 | #1F2329 / #5F6473 / #8B8FA3 / #FFFFFF | 文本、页脚、边框 |

- 面积分配：主色 ≤60%（封面/扉页可超）、辅色 ≤30%、强调色 ≤10%（Hero 页 ≤15%）
- 每页强调色只出现在焦点元素

## 字体
- 中文：PingFang SC / Microsoft YaHei；数字/英文：system 等宽栈（ui-monospace）用于巨型数字

## 全局规则
- 每页至少 1 个视觉锚点（≥44px 元素或大色块）
- 常规页留白 ≤35%；连续 2 页版式不得重复
- 视觉锚点：巨型数字（>64px）、大色块（三栏示意）、全屏渐变（封面/扉页/结束）
- 示意图形：用色块 + 文字模拟产品界面（三栏布局、对话气泡、表格行），不引入外部图片
- 非对称页：7 页（4/5/7/8/9/11/12）；对称页：2 页（2 目录、14 结束）
